# CampusEats Task Tracker

A small team repository for practising GitHub Flow, pull requests, issue tracking,
automated CI checks, and secure development in SE3090 Lab 08.

## Workflow

Keep main deployable. Create a short-lived feature, fix, or chore branch, make
conventional commits, open a pull request, review the diff and passing checks,
and merge. Link completed work to an issue with Closes #<number>.

## Local checks

Run `npm ci`, `npm test`, and `npm audit` after the quality improvements are merged.
Never commit API keys, passwords, .env files, or generated dependency folders.
